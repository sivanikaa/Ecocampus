 EcoCampus

**Building a Greener Future, One Campus at a Time.**

EcoCampus is a web-based project focused on campus sustainability and environmental awareness. It aims to encourage sustainable thinking and promote environmentally responsible practices through a digital platform.
 **Live Demo:** https://ecocampusss.netlify.app

##  Project Overview

Environmental sustainability is becoming increasingly important in educational institutions. EcoCampus explores how web technology can help communicate sustainability initiatives and encourage greener practices within campus communities.

The project demonstrates an approach to making sustainability more accessible through a digital experience.
